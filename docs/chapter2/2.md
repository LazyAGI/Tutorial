# 第2课时：LLM 训练范式与数据工程全景

## 1 预训练流程全览：从数据到模型

现在，我们已经了解了预训练的概念、目标以及常见任务。下一步，我们来看看实际操作中，模型是如何从“一堆原始数据”变成“能读懂语言的模型”的。

![](./assets/1.png)

整个流程可以分为几个关键环节：

**1️⃣ 数据收集与清洗**

预训练的第一步，就是把海量的文本、代码、图文等数据收集起来。这里的原则是：量大而广。

- **来源**：互联网网页、百科、书籍、开源代码仓库等。  
- **清洗**：去掉乱码、重复内容、敏感信息或违法内容。  
- **规范化**：统一编码格式、去除多余空格或特殊符号。  

> 💡 小提示：清洗干净的数据就像给模型打好基础——基础越稳，上层学习越容易。

**2️⃣ 分词与词表构建**

模型不能直接“看懂文字”，它只能理解数字。所以我们要把文本转成模型能处理的 token（最小语义单位）。

- **分词方法**：常用的有 BPE（字节对编码）、SentencePiece 等。  
- **词表大小**：越大能覆盖的词越多，但显存消耗也越高。  

打个比方：词表就像模型的“字典”，分词就是把句子拆成字典里的单词。

**3️⃣ 构建训练样本**

训练样本就是模型学习的“题目”。对于自监督预训练来说，这些题目通常是：

- **填空任务（Masked Language Modeling）**：随机遮住句子里的词，让模型预测它。  
- **下一个词预测（Next Token Prediction）**：给模型前面的内容，让它猜下一个词。  

这样，模型在练习中逐渐学会了语言的结构、上下文和语义关系。

**4️⃣ 模型选择与训练配置**

在准备好数据和样本后，就可以选择模型架构和训练策略了：

- **架构选择**：BERT（双向编码）、GPT（单向生成）、T5（编码-解码混合）。  
- **训练配置**：Batch 大小、学习率、优化器、训练轮数等。  
- **硬件需求**：预训练通常需要大量 GPU 或 TPU，模型越大，算力需求越高。  

> 💡 小技巧：对于初学者，可以先用小模型（如 GPT-2 small）尝试，把流程跑通再上大模型。

**5️⃣ 模型评估与保存**

训练过程中，需要定期评估模型的学习情况：

- **困惑度（Perplexity，公式定义见3.5节）**：衡量模型预测下一个词的准确性，越低越好。  
- **早停策略（Early Stopping）**：防止模型过拟合或浪费算力。  

训练完成后，把模型参数保存下来，下一步就可以进行微调或 SFT 了。
