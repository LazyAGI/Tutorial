# 第6课时：基于 LazyLLM 的数据-训练-推理全流程实践

==后补实践==

## 1. LazyLLM 框架深度解析

LazyLLM 是一个低代码大模型开发框架，旨在构建从数据到模型的迭代闭环。它通过高度抽象的组件，让开发者能够以最少的代码量实现复杂的 LLM 研发逻辑，解决开发链路碎片化的问题。

## 2. 任务定义与选型

本实践任务为中文机器阅读理解（MRC），即模型根据给定文章回答相关问题。

- 数据集：[CMRC 2018 (Chinese Machine Reading Comprehension)](https://huggingface.co/datasets/hfl/cmrc2018)。该数据集包含近 2 万个真实问题，适合验证模型的语义抽取与推理能力。
- 微调模型：Qwen2.5-1.5B-Instruct（暂定）。该模型参数量较小，对算力友好，且在中英文指令遵循及理解任务上表现优异。

## 3. 数据流 (Data Flow) 管理

利用 LazyLLM 的数据处理模块实现自动化流程：

- 数据筛选：自动清洗 CMRC 2018 中的长难句，剔除不符合长度要求的样本。
- 格式转换：将原始 JSON 格式的阅读理解数据（Context, Question, Answer）自动映射为模型所需的 Prompt 结构。
- 数据合成：探索使用内置工具对部分低质量数据进行改写或增强。

## 4. 模型流 (Model Flow) 训练

模型流涵盖了从权重加载到微调训练的全过程：

- 训练配置：采用 LoRA 轻量化微调技术，在保证效果的同时大幅降低显存占用。
- 自动化微调：调用 Finetune 模块，一键启动 Qwen2.5 在 CMRC 数据集上的迭代过程。
- 性能评估：训练过程中实时监控 Loss 变化，确保模型能够学习到阅读理解的特定模式。

## 5. 应用部署与服务化 (Serving)

训练完成后，LazyLLM 实现了从模型到服务的无缝衔接：

- 服务化部署：使用 Deploy 模块将训练好的权重一键转换为标准推理 API 接口。
- 动态扩容：支持基于推理负载的简单配置调整。

## 6. 一条龙流水线实战汇总

搭建一套完整的“数据清洗 -> 模型训练 -> 应用部署”流水线。通过一个主程序串联上述步骤，输入原始 CMRC 数据，最终输出一个可直接交互的智能阅读理解助手应用。
