# 第9课时：基于 LazyLLM 的预训练全链路实战

## 1. 任务目标

用 DuReader（千言）数据，在基座模型上对 DuReader 的篇章进行预训练（PT），使模型更好地拟合领域文本分布；并通过 prefix→continuation 续写评测集对比基座与预训练模型的 PPL、交叉熵 Loss 与 BLEU。

## 2. 数据集简介

### 2.1 数据的来源背景

- **名称**：[DuReader（千言·阅读理解）](https://huggingface.co/datasets/luozhouyang/dureader)，HuggingFace 标识 `luozhouyang/dureader`。
- **背景**：源自百度 DuReader 与千言数据集，面向中文机器阅读理解与鲁棒性评测，包含真实场景的篇章与人工标注问答。
- **子集**：使用 **robust（鲁棒性）** 配置的 train split；对每条样本取篇章正文，去重后得到唯一 context 列表。

### 2.2 数据集的规模

| 项目 | 数值 |
|------|------|
| 训练用篇章 | 3,000 条（从去重后 context 中取，见数据处理流程） |
| 训练集文件 | `data/dureader_train.json` |
| 评测用 prefix/continuation | 200 条，来自 `data/dureader_eval.jsonl` |

## 3. 数据处理流程

- **加载**：从 `luozhouyang/dureader` 的 **robust** 子集加载 train split。

### 3.2 关键代码

入口脚本：`run_dureader.py`，支持 `--mode prepare | train | eval | full`。

```python
# run_dureader.py 句子边界切分函数
def _split_at_sentence_boundary(text, target_ratio=0.5):
    n = len(text)
    if not n or target_ratio <= 0 or target_ratio >= 1:
        return text[: n // 2], text[n // 2 :]
    target_pos = int(n * target_ratio)
    pattern = re.compile(f'[{re.escape(SENTENCE_END_CHARS)}]')
    matches = list(pattern.finditer(text))
    if not matches:
        return text[:target_pos], text[target_pos:]
    best_pos = 0
    best_dist = abs(0 - target_pos)
    for m in matches:
        end = m.end()
        if end >= n:
            continue
        dist = abs(end - target_pos)
        if dist < best_dist:
            best_dist = dist
            best_pos = end
    prefix, continuation = text[:best_pos].strip(), text[best_pos:].strip()
    if not prefix or not continuation:
        return text[:target_pos], text[target_pos:]
    return prefix, continuation
```

通过在文本中寻找最接近目标长度比例的句子结束符，将输入切分为 `prefix` 与 `continuation`，用于后续评测集构造。

```python
# run_dureader.py prepare_dataset() 核心逻辑
dataset = load_dataset('luozhouyang/dureader', 'robust', trust_remote_code=True)
# 去重得到 all_contexts
for item in train_split:
    context = _get_context(item)
    if context and context not in seen:
        seen.add(context)
        all_contexts.append(context)

n_train = min(TRAIN_SAMPLES, len(all_contexts))
n_eval = min(EVAL_SAMPLES, len(all_contexts) - n_train)
train_contexts = all_contexts[:n_train]
eval_contexts = all_contexts[:n_eval]

# 训练集写 JSON
json.dump([{'text': c} for c in train_contexts], f, ...)
# 评测集：按句子边界切分后写 JSONL
for ctx in eval_contexts:
    prefix, continuation = _split_at_sentence_boundary(ctx, target_ratio=PREFIX_RATIO)
    eval_samples.append({'prefix': prefix, 'continuation': continuation})
```

此函数加载 DuReader 数据集，先对上下文去重并截取训练/评测样本；训练集写入 JSON，评测集再按句子边界切分并写入 JSONL。

### 3.3 涉及「算子」说明

> 本流程为自定义字段抽取算子，非 LazyLLM 管道算子

| 逻辑单元 | 输入 | 输出 | 功能 |
|----------|------|------|------|
| 上下文抽取 `_get_context(item)` | 原始条目 item | 字符串 context 或空 | 从 context / passage / content / doc / positive 等字段取篇章正文；doc 为列表时用换行拼接。 |
| 句子边界切分 `_split_at_sentence_boundary(text, target_ratio)` | 正文 text，目标比例 | `(prefix, continuation)` | 在接近 `target_ratio` 长度的句子边界处切分，使 prefix/continuation 均为完整句子；句子结束符为 `。！？；\n`。 |

## 4. 模型训练

- **基座**：Qwen2.5-0.5B-Instruct（`BASE_MODEL_PATH`）。
- **方式**：LLaMA-Factory 的 PT 阶段，全参数、cosine 学习率，在 `data/dureader_train.json` 上做语言模型续写训练。

**关键代码（节选）**：

```python
# run_dureader.py run_train()
model = lazyllm.TrainableModule(BASE_MODEL_PATH, target_path=target_path)
model.mode('finetune')\
    .trainset(TRAIN_JSON_PATH)\
    .finetune_method((finetune.llamafactory, {
        'stage': 'pt',
        'finetuning_type': 'full',
        'learning_rate': 3e-5,
        'cutoff_len': 512,
        'val_size': 0.05,
        'optim': 'adamw_torch_fused',
        'bf16': True,
        'fp16': False,
        'per_device_train_batch_size': 8,
        'gradient_accumulation_steps': 4,
        'num_train_epochs': 20,
        'lr_scheduler_type': 'cosine',
        'warmup_ratio': 0.1,
        'save_steps': 20,
        'logging_steps': 5,
        'resume_from_checkpoint': None,
        'save_strategy': 'steps',
        'save_total_limit': 5,
        'launcher': launchers.empty(ngpus=1),
    }))\
    .update()
```

- 参数含义：
    - `cutoff_len=512`：单条样本最大 token 长度，超出部分会被截断。
    - `per_device_train_batch_size=8`：每张 GPU 每步实际加载的样本数。
    - `gradient_accumulation_steps=4`：梯度累积步数，每 4 步再做一次参数更新。
    - `num_train_epochs=20`：完整遍历训练集的轮数。
    - `learning_rate=3e-5`：优化器的初始学习率。
    - `val_size=0.05`：从训练数据中划出 5% 作为验证集。
    - `warmup_ratio=0.1`：训练前 10% 的步数用于学习率预热。
    - `save_steps=20`：每训练 20 步保存一次 checkpoint。
    - `save_total_limit=5`：最多保留最近 5 个 checkpoint，旧的会被清理。

> 注意：checkpoint 带时间戳保存至 `pretrain_ckpt/qwen2_5_0_5b_dureader_{timestamp}`。

## 5. 效果评测

- **数据**：`data/dureader_eval.jsonl`（200 条，每行 `{"prefix": "...", "continuation": "..."}`）。
- **方式**：给定 prefix，在 continuation 上计算条件 PPL 与交叉熵 loss；另用模型自回归生成续写，与 reference continuation 比较 BLEU（2-gram F1 近似）。
- **脚本**：`run_dureader.py --mode eval`（基座与预训练模型同一套数据与指标）；结果写入 `results/{时间戳}/eval_pt_dureader_metrics.json` 与 `eval_pt_dureader_results.jsonl`。

### 5.1 PPL（困惑度）

- **定义**：语料级 PPL = exp(平均交叉熵 loss)，即对每条样本在 continuation 部分计算 token 级交叉熵 loss，再对全体样本取平均得到 $\bar{L}$。

$$
\mathrm{PPL} = \exp(\bar{L})
$$

其中平均 loss 为：

$$
\bar{L} = -\frac{1}{N}\sum_{i=1}^{N} \log p_\theta(w_i \mid w_{<i})
$$

在实际评测中，对每条样本在 continuation 部分计算 token 级交叉熵 loss，再对全体样本取平均得到 $\bar{L}$，最终报告 $\mathrm{PPL} = \exp(\bar{L})$。

- **变量说明**：$N$ 为 continuation 部分的 token 总数；$w_i$ 为第 $i$ 个 token；$w_{<i}$ 为第 $i$ 个 token 之前的上下文（prefix + 已生成 token）；$p_\theta(\cdot)$ 为模型参数 $\theta$ 下的预测概率；$\bar{L}$ 为平均交叉熵 loss。

**含义**：越低越好，表示模型对给定 prefix 下 continuation 的预测越准确。

### 5.2 Loss（交叉熵损失）

**定义**：上述 avg_loss，即 continuation 上 token 级交叉熵的平均。

$$
\bar{L} = -\frac{1}{N}\sum_{i=1}^{N} \log p_\theta(w_i \mid w_{<i})
$$

即 continuation 上 token 级负对数似然（NLL）的平均值。

- **变量说明**：$N$ 为 continuation token 总数；$p_\theta(w_i \mid w_{<i})$ 为模型对第 $i$ 个 token 的条件概率。

- **含义**：越低越好。Loss 与 PPL 的关系为 $\mathrm{PPL} = \exp(\mathrm{Loss})$。

### 5.3 BLEU（2-gram F1 近似）

- **定义**：给定 prefix，模型生成续写文本 $G$，参考文本为 $R$。对两者去空格后计算 2-gram F1：

$$
\mathrm{Precision} = \frac{|G_{2} \cap R_{2}|}{|G_{2}|}
$$

$$
\mathrm{Recall} = \frac{|G_{2} \cap R_{2}|}{|R_{2}|}
$$

$$
F_1 = \frac{2 \cdot \mathrm{Precision} \cdot \mathrm{Recall}}{\mathrm{Precision} + \mathrm{Recall}}
$$

最终在所有样本上取平均得到 BLEU 评分。

- *变量说明**：$G_2$ 为生成文本中的 2-gram 集合；$R_2$ 为参考文本中的 2-gram 集合；$|G_2 \cap R_2|$ 为生成与参考共享的 2-gram 数量。

- **含义**：越高越好，表示生成续写与参考在 n-gram 重叠上越接近。

## 6. 评测结果

在 DuReader 评测集（200 条 prefix→continuation）上运行 `run_dureader.py --mode eval`，得到如下对比结果：

| 模型 | PPL | Loss | BLEU |
|------|-----|------|------|
| 基座模型 | 27.5429 | 3.3157 | 0.1194 |
| 预训练模型 | 1.9688 | 0.6774 | 0.1786 |

- **PPL 改善明显**：由 27.5429 降至 1.9688（约下降 92.85%），表示模型在给定 prefix 后，对 continuation 的不确定性显著降低。
- **Loss 同步下降**：由 3.3157 降至 0.6774（约下降 79.57%），说明 token 级条件概率分布更接近真实答案。
- **BLEU 稳定提升**：由 0.1194 升至 0.1786（约提升 49.58%），反映生成文本与参考文本在局部 n-gram 上更一致。

预训练模型在三项指标上均优于基座模型，说明领域继续预训练有效提升了 DuReader 场景下的续写能力。PPL/Loss 对语言建模能力更敏感，BLEU 还受表达多样性影响；因此在仅做 PT（未做监督对齐）时，BLEU 通常提升幅度会小于困惑度类指标。

本课时从 DuReader 数据准备、LLaMA-Factory 全参数 PT、到 prefix→continuation 的 PPL/loss/BLEU 评测，形成一条可复现的 LazyLLM 预训练实践闭环。
